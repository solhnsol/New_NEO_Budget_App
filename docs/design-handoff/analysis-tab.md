# 분석 탭: 시안에 없어서 임의로 정한 것

시안(design-v2/polish/analysis-v5, analysis-v6 갤러리)을 그대로 옮기면서 시안에 없던 부분을 이렇게 정했어요. 확정이 필요해요.

- 위젯 크기: 아이폰 위젯 기준. 좌우 여백 26, 위젯 사이 22, 큰 위젯 높이 = 작은 위젯 두 개 + 사이 + 16. 화면 폭에 맞춰 작게(2×2)·중간(4×2)·크게(4×4)가 함께 늘어나요.
- 데이터가 아직 없는 위젯은 고정 예시 값: 오늘 쓸 수 있는 돈(30,050원), 들어온 돈(2,100,000원), 일정별(띠 비율). 예산은 80만 고정이고 "예산의 N%", 게이지는 쓴 돈 ÷ 80만으로 계산해요.
- 눈금: 게이지의 검정 눈금은 54% 위치에 고정(시안과 같음). 실제 의미(오늘까지 균등하게 썼을 때의 위치 등)는 정해야 해요.
- 위젯을 누르면 "모든 분석"(기존 상세 화면)이 열려요. 시안에는 이 화면이 없어요. 기존 "모든 분석" 줄은 시안에 없어서 뺐어요.
- 분류 타일 색은 분류 순서대로 주황·파랑·초록·보라(9% 바탕, 아이콘 #4E5968). 분류와 색의 고정 대응이 필요해요.
- 쓴 돈이 큰 일정 카드 바탕은 주황·주황·파랑·파랑 순서. 실제 캘린더 색에서 가져와야 해요. 시안의 "정산 대기 중" 배지는 위젯 안에 데이터가 없어 뺐어요.
- 위젯 추가 목록: 시안 v5(크기 칩 + 추가 버튼)와 v6(항목 → 갤러리) 중 v6. 항목 왼쪽 그림은 작은 막대 모양 자리 표시로, 항목별 실제 미리보기 그림이 필요해요.
- 갤러리 항목 이름은 시안 순서를 따랐고, 같은 "숫자"가 여럿(쓴 돈·들어온 돈 등)이에요.
- 고정 지출 중간 크기(목록)는 고정 지출 개별 데이터가 위젯 쪽에 없어 아직 없어요(작게만).
- 월 선택은 메뉴(최근 6개월)로 구현했어요. 시안은 "11월 ⌄"만 있어요.
- 큰 위젯이 있을 때 아랫줄을 16만큼 내리는 규칙은 아이폰 위젯 치수를 따라 정했어요.
