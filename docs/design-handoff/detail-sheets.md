# 일정 상세 · 거래 상세 · 정산 시트: 시안에 없거나 데이터가 없는 것

시안: `design-v2/FULL-2/3/4`, `DETAIL-1/2/4`, `polish/CHANGES.md`(우선), `ledger/palette.html`. 구현: `Support/Design/SheetParts.swift`, `Timeline/EventDetailView.swift`, `Ledger/TransactionDetailView.swift`, `Settlement/SettlementSheet.swift`.

## 시안에 있지만 데이터가 없어 뺀 것
- 거래의 결제 수단(삼성카드): `TransactionMarker`에 계좌·카드 이름이 없어요. 거래 상세의 부제와 `결제 수단` 행을 뺐어요.
- 정산 행의 `받을 돈 9,500원 ›` 값: 일정 시트는 정산 데이터를 읽지 않아 `정산하기 ›`만 보여요.

## 시안에 없어서 보탠 것
- 정산 시트 `사람 고르기`·`총 인원`·직접 입력 금액: 시안은 요청 후 모습만 있어요. 요청 전 입력 상태를 같은 행 모양으로 이었어요.
- 거래의 `돌려받은 돈`·`실제 부담`, 일정의 `환불` 행: 기존 데이터 유지용이에요.
- 정산 요청 후 버튼은 시안의 `입금 확인` 대신 `확인`(닫기)이에요. 입금 확인은 정산 허브 흐름이라 이 시트에서 열지 않았어요.
- 일정 시트의 `편집` 버튼은 기존 `무엇을, 어디서, 누구와` 시트로 가요(시안 DETAIL-5의 편집 폼은 다른 작업).
