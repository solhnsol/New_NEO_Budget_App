# 가계부 목록 + 선택 모드: 시안에 없어서 정한 것

시안: `design-v2/polish/ledger-v20.html`(목록), `select-v1.html`(선택 모드), `ledger/palette.html`, `polish/CHANGES.md`.
코드: `Ledger/LedgerScreen.swift`, `LedgerListViews.swift`, `LedgerSelection.swift`, `LedgerSelectionSheets.swift`.

## 시안에 없어서 임의로 정한 것
- **헤더 제목**: 시안 목록 화면은 "11월"인데, 앱의 목록은 여러 달을 한 번에 이어서 보여 줘요. 그래서 제목은 "가계부", 날짜 카드 제목은 "3일 화요일"이고 달이 바뀌는 첫 카드에만 "11월 3일 화요일"로 달을 붙여요.
- **주 띠(날짜별 쓴 돈)**: 시안 목록 화면에 있지만 앱 목록은 날짜가 이어진 한 줄이라 넣지 않았어요. 필요하면 달력 탭과 같은 주 띠를 위에 붙이는 결정이 필요해요.
- **검색 아이콘**: 시안 헤더에 있지만 목록 검색 기능이 아직 없어서 뺐어요(눌러도 아무 일 없는 아이콘은 두지 않았어요).
- **더 보기 메뉴(점 세 개)**: 시안에 없는 기능(계좌·카드 보기, 정산, 사람, 받은 알림)이 이미 앱에 있어서 헤더의 + 옆에 메뉴 하나로 모았어요. 정산 칩("정산 받을 돈 N원 ›")은 시안대로 제목 아래에 두었고(시연 데이터에는 받을 돈이 없어 캡처에는 안 보여요), 받을 돈이 0이면 숨겨요.
- **계좌·카드 화면**: 이번 범위 밖이라 `AccountsView`는 그대로예요. 헤더만 같은 모양으로 위에 얹혀요.
- **일정 묶음 색**: 시안의 색 박스는 캘린더 색인데, 거래 쪽에는 그 일정의 캘린더 색이 없어요. 일정 id로 파랑·주황·초록·보라 중 하나를 고정해서 골라요. 캘린더 색을 거래 항목에 실어 주면 바꿔야 해요.
- **행 둘째 줄**: 시안은 카드 이름("삼성카드")인데 거래 항목에 카드 이름이 없어요. 시각 · 환불/직접 입력 · 태그를 써요(일정 박스 안에서는 일정 이름은 뺐어요).
- **환불·정산·대기 줄**: 시안에 없는 상태(환불 19,000, ○○ 정산, 정산 대기 중)는 행 제목 아래 13px 옅은 줄과 작은 배지로 그대로 두었어요. 환불 행의 금액은 들어온 돈이라 빨강 600 + 부호예요.
- **금액 표기**: 행 금액은 시안처럼 "원"을 빼고 "−5,800" / "+19,000"이에요. 합계·선택 합계·정산 칩은 "원"이 붙어요. 원화가 아닌 통화는 통화 표기를 그대로 써요.
- **정리할 입금 카드**: 시안에 없어요. 같은 흰 카드 + 행 모양에 둥근 연한 빨강 타일로 맞췄고, 길게 눌러 끌어다 놓는 동작은 그대로예요. 안내 문구는 지웠어요.
- **빈 화면·불러오는 중**: 시안에 없어서 가운데 옅은 글자 한 줄, 스피너만 둬요.
- **삭제 알림**: 시안 모양대로 직접 그린 카드(반경 24, 취소 회색, 삭제 #E5484D)예요. "카드·통장에서 온 거래는 지울 수 없어요" 같은 안내는 시스템 알림 그대로예요.
- **선택 모드 진입/해제**: 길게 누름 350ms + 햅틱, 선택 박스 150ms, 작업 바 240ms 스프링은 CHANGES.md의 모션 힌트를 따랐어요(모션은 나중에 다시 다듬기로 한 범위).
- **선택 박스**: 이어진 선택은 한 박스(연한 파랑 + 1.5 파랑 테두리, 반경 12)로 묶여요. 일정 박스 경계를 넘어서는 이어 붙이지 않아요.

## 건드리지 않은 곳
- 일정 고르기 화면(`LedgerEventPicker`), 거래 상세, 정산·사람·받은 알림 화면, 정산 시트는 다른 스레드 범위라 그대로예요.
- 공통 부품은 바꾸지 않았고, 선 아이콘만 새로 추가했어요(`line-cat`, `line-tag`, `line-trash`, `line-house`, `line-heart`, `line-ticket`, `line-plane`, `line-gift`, `line-wifi`).
