# 캘린더 탭 시안 반영: 디자이너 팀에 넘길 내용

캘린더 탭을 시안(`design-v2/polish`의 cal-v5, ledger-v20)과 같은 모양으로 맞추면서 화면에서 빠졌거나 시안에 없는 것을 정리해요. 동작과 모션은 시안 단계부터 다시 짜기로 해서 건드리지 않았어요.

## 시안에 없어서 화면에서 뺀 것

| 항목 | 예전 위치 | 지금 | 디자이너 팀이 정할 것 |
|---|---|---|---|
| 오늘 버튼 | 헤더 오른쪽 "오늘" | 없음 (주 띠에서 날짜를 직접 골라야 해요) | 오늘로 돌아가는 방법과 모양 |
| 계좌·카드 진입 | 헤더 메뉴 "계좌·카드" | 없음 (코드의 `LedgerDestination.accounts`는 남아 있어요) | 어디서 들어가는지(더보기 탭 등) |
| 시간표/하루씩 전환 | 헤더 버튼 | 없음. 캘린더 세그먼트를 길게 누르면 전환돼요(임시) | 시간표 보기를 계속 둘지 |
| 월 제목 줄 | 월 격자 위 "2026년 11월"과 좌우 화살표 | 없음. 헤더 "11월"이 열린 월을 따라가고 좌우 스와이프로 이동해요 | 월 이동 화살표가 필요한지, 연도 표시 |
| 가계부 목록 | 헤더 메뉴 "가계부 목록" | 세그먼트의 목록 아이콘이 같은 화면을 열어요 | 목록 화면 자체의 시안 |
| 검색 | 없었음 | 아이콘만 있고 동작 없음 | 검색 화면과 동작 |
| 내역 추가 | 헤더 메뉴 "내역 추가" | 플러스 아이콘이 같은 시트를 열어요 | 거래·일정 중 무엇을 만드는지 |

## 시안과 앱 데이터가 달라서 생기는 차이

- 날짜 제목 오른쪽 글(`진행 중 · 운동`, `일정 4개`, `쓴 돈 …`)과 종일 일정 칩은 앱의 기존 문구와 위치를 그대로 써요. 시안의 "도움말 문구 없음" 규칙에 맞는지 확인이 필요해요.
- 일정 색은 기기 캘린더 색을 그대로 써서, 시안의 고정 팔레트(파랑·주황·초록·보라)와 다를 수 있어요.
- 거래 행의 분류 아이콘은 시안의 6종(카페, 식사, 교통, 도서, 쇼핑, 기타=은행)만 써요. 분류가 더 필요하면 아이콘을 추가로 그려야 해요.
- 월 격자 아래에 시안처럼 별도 카드로 날짜 목록이 나뉘지 않고, 하나의 흰 카드가 이어져요.
- 정산 받을 돈 칩(ledger-v20 월 격자 위)은 아직 넣지 않았어요.

## 글꼴·아이콘

- Pretendard(Regular, Medium, SemiBold, Bold)를 `Fonts/`에 번들했어요. 라이선스는 `Pretendard-OFL-LICENSE.txt`. 캘린더 탭에서만 쓰고, 다른 탭은 아직 시스템 글꼴이에요.
- 라인 아이콘 12종은 시안의 SVG 그대로 `Assets.xcassets/line-*`에 있어요.

## 더보기 탭 (설정) 재작성 — 시안에 없어서 임의로 둔 것
- 반복 지출 알림 상세: 시안에 없음. "결제 하루 전", "금액이 달라졌을 때" 두 스위치로 임시 구성.
- 받은 알림 내역: 시안의 "규칙 → 가맹점 · 금액" 줄은 데이터가 없어 처리 결과 문구(IntakeText.status)로 대체. 알림 상세의 "적용된 규칙", "읽어낸 값"은 규칙 엔진이 없어 뺌.
- 알림 처리 규칙 목록·수정, 예산, 알림 종류별 옵션, 테스터용 내보내기, CSV 가져오기, 받을 앱 스위치는 모양만(저장·동작 없음). 저장되는 것은 알림 종류 마스터 스위치, 방해 금지, 정산 초과분 처리 방식뿐.
- 캘린더·분류 규칙·계좌·카드 화면은 기존 List 화면 그대로(시스템 내비게이션 바). 시안 스타일 재작성은 다음 작업.
- 시안의 "보여줄 데이터"(S1) 화면은 더보기 맨 위 세그먼트로 대체되어 별도 화면 없음. 알림 설정 모음(S9)도 더보기의 알림 섹션이 대신함.
- 디버그 전용: `-more-screen <이름>`, `-tab-more` 실행 인자로 화면을 바로 열 수 있음(MoreGallery).
