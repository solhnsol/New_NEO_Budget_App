# 시간축 정리 (DEBUG Temporal Grid)

기준 `76b1dbc`. 시간축 표현만 변경(분할·핀치·날짜 이동·Browse·EventKit·편집·Focus 불변).

## 변경
- 압축 레일(지그재그·점선·유형별 스타일)과 `SlotCompression` 제거. 세로축은 **항상 같은 가는 실선 하나**(0.8pt).
- `HourAxis`(순수, `TemporalGridTicks.swift`): 눈금의 **위치와 표시 여부를 분리**.
  - 위치: 항상 지금 그려지는 파티션의 `timeToY(hour·60)` (확대·날짜 이동 중에도).
  - 표시 여부: 25개 정각의 고정 중요도 순서(0, 24, 12, 6, 18, 3, 9, 15, 21, 2, 4, 8, 10, 14, 16, 20, 22, 나머지)와 **그 순간의 공간**만으로 결정. 한 정각은 자신보다 중요한 모든 정각과의 거리가 `tickGap`(5pt)보다 가까우면 눈금이, `라벨 높이+4pt`보다 가까우면 라벨이 없고, 그 위로 4pt/8pt 램프 동안 smoothstep opacity로 0 → 1. 눈금 통합·범위 요약 없음(공간이 없으면 해당 정각만 생략).
  - 줌 임계값·기억된 집합·타이머 없음. 간격은 줌에 비례해 연속으로 커지므로 확대하면 눈금(먼저)과 라벨(나중)이 나타나고, 축소하면 같은 경로로 사라진다(순수 함수라 방향·경로와 무관).
  - 날짜 이동 중에는 보간된 파티션 위에서 눈금이 연속 이동하고 opacity는 변하는 간격을 따라간다. 라벨은 위치가 같은 정각 라벨 그대로라 교차 페이드·겹침 없음.
  - 화면 위·아래 경계: 첫/마지막 라벨(00:00, 24:00)은 가장자리에 붙고, 나머지는 가장자리에 닿기 전에 페이드아웃(잘림 없음). Dynamic Type: 라벨 폰트는 ×1.4까지 따라가고(축 열 폭이 고정) 그 이상은 더 크게 하지 않는다. 글자가 커지면 라벨 간격이 커져 더 적은 라벨이 쓰인다.
- 이전의 "그리드 경계 우선" 규칙은 없앴다(경계가 날짜에 따라 움직이면 우선순위가 바뀌어 전환 중 점프가 생김). 중요도는 시간 구조 기준으로 고정.

## 검증
- 테스트 `HourAxisTests`(8개): 눈금 y가 `timeToY`와 정확히 일치(오차 0, `yToTime` 왕복 1e-9), 모든 fixture × N=10/12/16 × 글자 ×1/2.2/3 × 줌 1~8(0.1 간격)에서 **둘 다 보이는 라벨 쌍의 간격 > 라벨 높이+여백, 눈금 쌍 간격 > 5pt(충돌 0건)**, 줌 1→8(1% 간격 700스텝)에서 opacity가 **한 번도 감소하지 않음**(확대는 추가만), 같은 줌에서 올라갈 때와 내려올 때의 상태가 **완전히 같음**(역순 재현), 줌 1%당 opacity 변화 최대 0.048, 날짜 이동 1%당 최대 0.130(-demo-trans, 1×) / 0.055(3×), 1%당 눈금 y 이동은 유한(점프 없음), 날짜 이동 전진/후진(p 0↔1 반전) 상태 일치, 가장자리 라벨 페이드, 텍스트 크기별 라벨 수. 기존 핀치·분할·글자 충돌 테스트는 새 축 API로 갱신해 통과.
- 시뮬레이터: 1×/2×/3×/8×, N=16, 글자 ×3, p=0/0.25/0.5/0.75/1 스크린샷, 두 손가락 핀치(3.7×)에서 눈금·앵커·스크롤 정상, 녹화 `zoom-1-8-1.mp4`(자동 1→8→1, 화면 중앙 앵커), `day-move-reversal.mp4`(p 0→1, 반전해 0.5까지, 다시 1로). 녹화 영상 자체는 열어 보지 못했고 스크린샷과 테스트로 검증했다.

## 성능 비용
- 눈금 계산(25개, 중요도 비교 ≈300쌍): **프레임당 0.07ms (Debug)**. 분할 계산·프로필 계산 0회(핀치 중 "최적화 4회" 유지), 눈금 계획 캐시도 필요 없어 제거. 눈금 뷰는 최대 25개 + 라벨 25개.

## 남은 문제
- 경계 시각 라벨 우선 규칙이 없어, 압축 구간에서는 셀 경계 정각이 라벨 없이 눈금만 있을 수 있다(예: 1×에서 07:00).
- 날짜 이동 중 라벨 opacity는 간격 변화에 따라 부드럽게 바뀌지만 이동량이 큰 날 쌍(최대 130분 경계 이동)에서는 라벨이 사라졌다 나타나는 것이 읽기에 거슬리는지 실기기 평가가 필요하다.
- 라벨 폰트가 ×1.4를 넘지 않는다(축 열 폭 고정). 접근성 큰 글자에서의 정책은 미정.
