# Browse 고정 그리드: 시간 조정 연결 (Phase 3A)

설계와 결과: `docs/development/phase3a-integration.md`.

iPhone 18 Pro 시뮬레이터에 실터치를 넣어 확인했다. 실행 인자는 `-demo -browse-temporal`이다. 길게 누르기와 끌기는 `touch_path`로 손가락을 실제로 붙잡고 움직였다.

| 파일 | 내용 |
|---|---|
| `01-enter-session.png` | "영어 회화"(반복)를 길게 눌러 세션을 열었다. 고정된 그리드 위에 윤곽선과 두 핸들이 보이고, 아래에 편집 바(제목, 오후 4:00 – 5:00, 취소/완료)가 있다. |
| `02-drag-end-bubble.png` | 끝 핸들을 끌어 오후 6:00에 놓았다. 15분 격자에 맞는다. 카드는 캘린더 색으로 채워지고 원래 카드는 흐리다. 종료 말풍선은 편집 바 위로 뒤집혀 화살표와 함께 뜬다. 편집 바에는 "끝 +1시간"이 보인다. |
| `03-recurring-asks-scope.png` | 완료: 반복 일정이라 "이 일정만 / 모든 반복 일정"을 묻는다. 저장 중에는 핸들·말풍선을 숨기고, 버튼은 진행 표시로 바뀐다. |
| `04-saved-series.png` | "모든 반복 일정"을 골라 저장했다. 캘린더를 다시 읽어 16:00–18:00으로 보이고, 세션은 끝났다. |
| `05-drag-start-bubble.png` | 14일 "팀 회의"(단일)의 시작 핸들을 끌었다. 오후 1:30, "시작 −1시간 30분". 시작 말풍선은 핸들 위에 뜬다. |
| `06-outside-taps-save.png` | 빈 격자를 두 번 탭했다. 첫 탭은 핸들 선택만 풀고, 두 번째 탭은 기본 정책(commit)으로 저장한다. 결과는 13:30–16:00이다. **이 화면의 13일 "스터디" 카드 안 거래 줄 글자 겹침은 편집과 무관한 렌더 문제였다(문서 4절, 고친 결과는 07).** |
| `07-inside-rows-after-fix.png` | 06과 같은 순서(팀 회의 시작 13:30, 빈 격자 두 번 탭) 뒤의 화면. "스터디" 안쪽 줄 "카페 4,800원 / 편의점 3,500원"이 한 줄씩 보이고, "분식"(13:20, 점심 약속에 연결됐지만 그 시간 밖)은 글자 없이 점만 남는다. 그 점을 누르면 "분식 / 점심 약속"을 묻고, 스터디 카드를 누르면 스터디가 열린다. 붉은 가로선은 현재 시각선이다. |

이 밖에 같은 실행에서 확인한 것:

- ±15분 버튼을 누르면 같은 프레임에 카드·편집 바·말풍선 시각이 함께 바뀐다(6:15 → 6:30).
- "이 일정만" 저장 뒤 진단 줄(`-browse-temporal-edit-probe`)에 앵커 오차 0.00pt, `ended(committed)`가 찍혔다.
