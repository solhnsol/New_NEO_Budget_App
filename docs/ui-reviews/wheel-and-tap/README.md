# Browse 고정 그리드: 시간 휠과 탭 두 단계

iPhone 18 Pro 시뮬레이터(전용 기기 `OnAll wheel+tap`)에 실터치를 넣어 확인했다. 실행 인자는 `-demo -browse-temporal`이다.

## 바뀐 조작

| 동작 | 전 | 지금 |
|---|---|---|
| 일정 탭 | 상세 시트 | **선택**: 윤곽선, 시작·끝 핸들, 편집 바 (시간 편집 세션) |
| 선택된 일정의 제목 탭 (카드 위쪽 30pt, 짧은 카드는 전체) | — | **이름 편집**: 키보드, 그 위에 캘린더 칩과 제목 칸 |
| 편집 바의 제목 탭 | — | 이름 편집 (VoiceOver로도 닿는 길) |
| 일정 길게 누르기 | 시간 편집 세션 | 상세 시트 (임시: 나중에 그 일정으로 확대) |
| 편집할 수 없는 일정 탭 | 상세 시트 | 상세 시트 (그대로) |
| 핸들 탭 | ±15분 말풍선 | **시간 휠** 말풍선 |

- 휠: 15분 간격, 가운데 줄이 그 끝의 시각이다. 손가락으로 돌리는 동안 한 줄씩 지날 때마다 카드·편집 바가 따라 바뀐다(햅틱 포함). 줄을 탭하면 그 줄로 돈다. 범위는 그날 안, 반대쪽 끝과 15분 이상이다. 원래 시각이 격자 밖(10:07 등)이면 그 시각도 한 줄로 남는다. 종료가 자정이면 "자정"으로 쓰고, 머리글 날짜가 다음 날을 말한다.
- 핸들을 끄는 동안 휠은 핸들을 따라 돌고 터치를 받지 않는다. VoiceOver는 머리글이 조정 요소다(위로 +15, 아래로 −15). 휠은 VoiceOver에서 숨긴다.
- 이름 편집: 탭 → 키보드. 바깥 탭·핸들 터치·키보드 내리기는 이름 편집만 끝낸다(입력은 유지). 키보드의 완료(리턴)와 편집 바의 완료는 시간과 이름을 **한 번에** 저장한다. 빈 제목은 저장하지 않고 원래 이름으로 돌아간다. 취소하면 입력도 버린다. 반복 일정이면 이름만 바꿔도 범위를 묻는다.
- 키보드가 올라와도 화면 배치는 그대로다(`ignoresSafeArea(.keyboard)`). 그리드 분할이 화면 높이로 계획되기 때문이다. 편집 바만 키보드 위로 올라간다. 확대 상태에서는 카드를 키보드 위로 스크롤한다.
- 캘린더 칩: 쓰기 가능한 캘린더를 보여 주고, 지금 캘린더를 채워 표시한다. **다른 캘린더로 옮기기는 아직 저장하지 않으므로 나머지 칩은 흐리게 두고 누르지 않는다.** 활동 정보가 캘린더 ID를 포함한 키로 저장되어, 옮기면 연결이 끊어진다. 공급자 계약과 키 이전 설계가 먼저다.

## 검증

- 패키지: 470 + 90 통과. `EventSavePipelineTests`에 이름 변경 3개를 추가했다(명령 모양, 저장과 다른 곳의 이름 변경 거부, 반복 일정 범위 질문).
- 앱: 488개 통과(전용 시뮬레이터). 추가한 테스트는 이름 편집 상태 전이, 제목 탭 판정, 휠 선택지·줄 이름, 휠로 끝·시작 바꾸기, 이름+시간 한 번 저장, 빈 제목, 취소다. Release 빌드도 성공했다.
- 공용 시뮬레이터(iPhone 18 Pro)에서는 다른 세션이 동시에 테스트를 돌려, 이 브랜치에 없는 테스트가 실패로 섞여 나왔다. 그래서 전용 기기를 만들어 다시 돌렸다.

## 고친 문제 (구현 중 발견)

- 말풍선을 `.offset`으로 놓으면 그 안의 UIKit 휠은 터치 영역이 원래 자리(오버레이 왼쪽 위)에 남았다. 보이는 휠을 끌면 그리드가 스크롤됐다. 이제 말풍선 본문은 레이아웃(`padding`)으로 놓는다. hit test 로그로 창 좌표가 그려진 자리와 같은 것을 확인했다.

## 남은 것

- **1×에서는 이름 편집 중 카드가 키보드에 가릴 수 있다.** 오후 일정이 그렇다. 스크롤할 여유가 없어서다. 입력은 편집 바에서 보이고, 카드에도 반영된다. 해결책 후보: 이름 편집 동안 잠깐 확대하기(다음 단계의 자동 확대와 같은 장치).
- **휠 말풍선이 위로 뒤집히면 카드 제목을 가린다.** 끝 핸들 아래에 편집 바가 있을 때다. 그때 제목을 누르려면 먼저 말풍선을 닫아야 한다. 배치 규칙은 3A 그대로다.
- **앱 실행 직후 첫 탭이 무시되는 것을 두 번 봤다.** 두 번째 탭부터는 된다. 시뮬레이터 입력 주입 탓인지 앱 탓인지 확인하지 못했고, 기준 커밋에서도 비교하지 않았다.
- 캘린더 옮기기 저장(위 설명). 거래 말풍선, 길게 눌러 자동 확대는 다음 단계다.
- VoiceOver 실기기, 실제 EventKit 이름 저장은 확인하지 않았다.
